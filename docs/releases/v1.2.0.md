## What's new

- **Compact Mode**: keep the location, current temperature, daily high/low, condition, local clock (when enabled), and animated weather background while moving daily and hourly forecasts into an on-demand dialog.
- **Both temperature units**: show Celsius and Fahrenheit simultaneously. The configured display unit remains the primary value, with the other scale shown alongside it.
- Both features are optional and can be enabled independently in the visual editor or YAML.
- Temperature conversion uses the active weather source or local sensor's own unit, including cards with multiple sources.
- New automated temperature, layout, editor and forecast interaction tests.

### Configuration example

```yaml
compact_mode: true
temperature_unit: F
show_both_units: true
```

Existing dashboards retain their original layout by default. For Sections dashboards with explicit grid row overrides, resize the existing cards or remove the override to reclaim vertical space.
